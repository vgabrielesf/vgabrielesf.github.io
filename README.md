## Como executar localmente
Você pode abrir o site localmente de duas formas:

### 1) Abrindo direto no navegador
1. Faça o clone do repositório:
   ```bash
   git clone https://github.com/vgabrielesf/vgabrielesf.github.io.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd vgabrielesf.github.io
   ```
3. Abra o arquivo `index.html` no navegador.

### 2) Usando um servidor local (recomendado)
Se o projeto usa rotas/requests que exigem servidor, rode um servidor simples.

- Com Python:
  ```bash
  python -m http.server 8000
  ```
  Acesse: `http://localhost:8000`

- Com Node.js (http-server):
  ```bash
  npx http-server -p 8000
  ```
  Acesse: `http://localhost:8000`
